# KNN-Classification

This project implements the K-Nearest Neighbors (KNN) algorithm on the Iris dataset, one of the most widely used datasets in machine learning. The model is trained to classify iris flowers into three species—Setosa, Versicolor, and Virginica—using features such as sepal length, sepal width, petal length, and petal width.

## Key Features
Data preprocessing and exploration
Visualization of Iris dataset features
K-Nearest Neighbors (KNN) classification
Model training and testing
Accuracy evaluation and performance analysis
Prediction of flower species from new input data

## Resume Project Description

Built a classification model using the K-Nearest Neighbors (KNN) algorithm on the Iris dataset to predict flower species based on morphological features. Performed data analysis, visualization, model training, and evaluation using Python and Scikit-learn, achieving high classification accuracy.
